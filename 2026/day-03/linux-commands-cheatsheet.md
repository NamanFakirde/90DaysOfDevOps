# Day 03 – Linux Commands Practice

## 1. Process Management
this commands are used to monitor system performance, manage services and control running services.
1. `ps`: Snapshot of current processes.
2. `top -h`: Real time display of system process and resource usage.
3. `kill <PID>`: Used to terminate the process using its PID.
4. `free -h`: Display the disk's free space and memory space.
5.  `killall <process-name>`: Terminate all processes with specific name.

## 2. File System
This commands are used to manipulate and interact with the file system.
1. `ls`: list the content of current directory.
2. `cd`: Change the current working directory.
3. `rm`: Used to remove a file.
4. `cat`: Displays the content of a file.
5. `head`: Returns starting 9-10 lines from a file.
6. `tail`: Returns bottom 5-10 lines from a file.
7. `cp`: Used to copy file from one place to another
8. `chmod`: Used to change & modify the file/directory permission.
9. `chgrp`: Used to change both owner and group of a file.
10. `mv`: This command is used for moving a file from one place to another and to rename a file both.

## 3. Networking Troubleshooting
This commands are used to monitor connectivity, ports and routing issues.
1. `ping`: Check connectivity between two nodes.
2. `ifconfig`: Shows wireless connection to the system.
3. `netstat`: Display network connection, routing tables and interface stats.
4. `curl`: Transfer data from a server.
5. `ip addr`: shows IP address of a host.
6. `mtr`: combines ping and traceroute into a real time report
